# Personas — Mid-Cycle Subscription Upgrade

## P1 — Standard Subscriber
Currently on the Standard plan ($20/mo, 2,000 chat credits, 3 chatbots, 1,000 document pages). Wants a
frictionless way to move to Premium mid-cycle without leaving the Billing page, and wants to know the
exact charge before committing.

## P2 — Premium Subscriber
Already on Premium ($40/mo). Should never be shown an upgrade path or be able to trigger a redundant
upgrade/charge.

## P3 — Demo Operator (dev/QA)
Exercises both payment outcomes deterministically by choosing an account email that does or doesn't
start with `fail`, with no external payment sandbox or toggle required.
